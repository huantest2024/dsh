## v1.0.7（2026-10-30）— 壳更新下载可靠性 + 静默安装后自动拉起

### 修复

1. **壳更新下载支持断点续传**：GitHub release-assets 会在传输中途掐断连接
   （实测 108MB 安装包在 26.5MB 处报 `end of response with 83467221 bytes missing`），
   v1.0.6 一次失败即整包重来，实际几乎装不上。现在改用 HTTP Range 从断点续传，
   最多续 8 次；服务器不接受 Range（返回 200 而非 206）时自动退回整包重下。
2. **安装包完整性校验**：下载完成后按 GitHub 资产 `digest` 的 sha256 校验，
   不匹配即删除重下，避免装到被截断的安装包。
3. **静默安装后自动拉起新版**：NSIS `/S` 会跳过图形安装流程的完成页，而
   electron-builder 的 `StartApp` 只挂在完成页上——所以装完不会自动启动，
   观感像「点安装没反应」。现在由分离的 cmd 等待安装器退出后 `start` 主程序
   （带 `--updated`），装完即回到应用窗口。
4. 进度条上限收敛到 99%，避免还没校验就把 100% 报给用户。

## v1.0.6（2026-10-27）— 壳更新下载修复

### 修复

1. **修复应用内「检查更新 → 下载安装包」一直失败**：下载代码把原生 fetch 返回的
   WHATWG ReadableStream 当成 node-fetch 的 Node 流用（`.on('data')` / `.pipe()`），
   一点下载就报 `res.body.on is not a function`。已改为 `for await` 逐块落盘，
   下载进度正常推送。
2. **下载通道改走 api.github.com 资产接口**（`Accept: application/octet-stream`），
   不再依赖 github.com 的首跳——公司网络下 api.github.com 稳定可达。
