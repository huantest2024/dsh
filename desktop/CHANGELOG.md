## v1.0.4（2026-10-16）— 秒开启动 · 服务常驻 · 更名 DSH Desktop

### 启动体验

1. **全新启动加载界面**：窗口出现瞬间即呈现完整界面骨架（悬浮侧栏、会话列表、
   输入区占位）与不定进度条 + 实时耗时，替代原启动卡片；服务就绪后无缝切入真实界面
2. **服务常驻，退出重开约 1.5 秒**：正常退出应用后 dsh 服务在后台保留，
   再次打开直接接续（此前每次重开需 6~9 秒冷启动）；后台最多保留 4 小时，
   到期自动结束，不会长期占用资源
3. **壳更新重启同样秒开**：壳自更新安装时只重启应用本身，后台服务原样接续

### 更名

4. **应用更名为「DSH Desktop」**：安装目录与桌面/开始菜单快捷方式与官方桌面版
   彻底区分（此前两者同名，安装其一会覆盖另一方的快捷方式）
5. 注意：本版使用全新数据目录（`%APPDATA%\DSH Desktop`），从 v1.0.3 升级后
   桌面壳设置需重新配置、运行时首次启动自动重新安装；会话与任务数据在
   用户目录 `~/.dsh`，不受影响

### 修复

6. **主题开启时侧栏调宽异常**：拖拽侧栏宽度或收起/展开时，卡片宽度会失控放大，
   已修复；展开为完整宽度、手柄始终贴合卡片边缘
7. **侧栏收起/展开动画卡顿**：切换动画期间不再逐帧重算背景模糊，动画更顺滑

## v1.0.3（2026-10-09）— 主题系统重做 + 壳内更新 + 视觉细节

### 主题系统（重做）

1. **主题 = 全局配色**：五套主题（阿尼亚粉暖 / 莉可丽丝红 / 约尔暗金紫 / 艾莉莎银蓝 /
   极简中性灰）经 dsh 官方配色变量整套覆盖，切换即全界面变色（侧栏/按钮/输入框/面板）
2. **主题卡 = 组合预览**：壁纸缩略图打底 + 右上角配色角标，点击应用整套
   （配色 + 推荐壁纸 + 推荐挂件）；背景与主题彻底解耦，单独换壁纸不动主题配色
3. **主题面板 Win11 设置式交互**：主页主题卡片网格 + 背景/挂件分组行 +
   动态效果平铺，壁纸/挂件管理收进子页（‹ 返回导航）
4. **恢复原生不再复活**：关闭主题后再点主题按钮显示「主题已关闭」空面板，
   只有显式点「开启主题」才恢复
5. **壳顶栏跟随主题强调色**：品牌名 / 🎨 / 版本徽章随主题染色，深浅切换不覆盖

### 新增

- **壳内更新**：点「检查更新」同一次检查 dsh 运行时与桌面壳自身（GitHub Releases），
  任一有新版即展示；壳更新下载（实时进度）→ 静默安装并重启，会话与设置不受影响。
  本版起不再需要手动去 GitHub 下载安装包
- **动态壁纸**：主题面板「背景」子页支持上传 mp4/webm（≤30MB），视频铺底 +
  截帧缩略图 + 删除管理；浓度遮罩照常生效

### 修复与细节

1. **侧栏悬浮形态无条件生效**：折叠椭圆胶囊（999px 圆角悬浮）与展开悬浮圆角卡片
   不再依赖主题开启状态，关闭主题也保持悬浮形态（仅玻璃染色随主题）
2. **挂件乱切**：随机套装在打开设置面板时不再重新抽图，仅切换套装/增删素材时重抽
3. **粒子形状**：樱花为带 V 形缺刻的花瓣形（粉白渐变+翻面透视），
  落雪为六角雪花（六主干+分叉+缓旋）
4. **版本更新弹窗深浅主题跟随**：跟随应用深浅模式实时切换配色
5. **主题插件防删自愈**：npm 对齐清掉本地插件时，壳启动自动从内置母本恢复

## v1.0.2（2026-09-23）— 更新与登录链路整体加固 + 壳内浏览器弹窗

### 修复

1. **版本说明弹窗整窗空白**：v1.0.1 单窗口化引入的样式优先级问题，发现新版本/
   安装进度/完成/失败四个阶段全部不可见。已修，各阶段视图正常切换
2. **应用内更新失败（EBUSY）**：Windows 下正在运行的 dsh 服务子进程占用运行时
   目录，npm 换包必然失败。现在安装前自动停服并按端口清扫残留进程，装完无论
   成败自动恢复服务；更新成功后界面原地切换到新版本，不再依赖重启生效
3. **点「检查更新」数秒无响应**：跳转此前被 GitHub 发布说明拉取阻塞（最长 15s）。
   现在发现新版本立即跳转，说明文字随后自动补上
4. **更新失败时看不到真实原因**：弹窗只显示「无安装输出」。现在重开窗口能看到
   完整的 npm 错误日志
5. **账号登录交换被平台拒绝（422）**：纯 web 部署缺少平台要求的客户端标识头。
   现在启动时自动补齐（对 dsh 运行时做幂等修正，更新后自动重打）
6. **登录页「返回 DeepSeek Harness」报系统错误**：该按钮使用桌面版专用深链，
   现在直接聚焦回应用主窗口

### 新增

- **壳内浏览器弹窗**：登录、平台页面在应用内以独立窗口打开（不再跳系统浏览器），
  顶部带浏览器式控制栏——后退/前进/刷新/在浏览器中打开，窗口可拖动；
  **F11 / ⛶ 全屏**（全屏时控制栏隐藏，鼠标移到屏幕顶缘悬浮浮现、移开立即隐藏，
  Esc 退出）；登录流程自动弹出授权页
- **「已是最新版本」提示常驻显示**，不再闪现后消失
- 版本说明页的**新版本号可直接点击**进入更新页

## v1.0.1（2026-09-18）— 更新链路五项修复 + 全新鲸鱼剪影图标

### 修复

1. **0.1.6-alpha.2 更新失败**：新版 dsh 的插件解析器只从 profile 自身的
   node_modules 解析插件，旧位置的主题插件会让服务启动即退出。现在每次启动
   自动检测并迁移插件到新位置（幂等，旧位置保留不动）
2. **更新失败回退链**：更新前记录版本锚点，新版本启动失败时优先恢复更新前版本，
   不再倒退到更旧的缓存版本（旧版读不了新版会话数据，曾导致左侧历史会话消失、
   新会话功能失效）；恢复失败才清除运行时回退本机 CLI，并弹窗说明会话找回办法
3. **检查更新不再另开弹窗**：发现新版本、更新说明、安装进度、完成/失败全部在
   「版本说明」同一窗口内以视图切换完成；「已是最新版本」「检查失败」改为窗口内
   就地提示；安装中关窗后台继续的行为不变
4. **后台启动崩溃**：以后台/分离方式启动（stdout 管道关闭）时点「检查更新」会
   触发主进程未捕获异常。现控制台日志输出在管道断裂时自动停用并静默处理
   （文件日志不受影响），任何启动方式均稳定
5. **右侧文件区面板全屏被顶栏遮挡**：全屏面板为 fixed 定位绕开文档级 30px 让位，
   现按稳定属性选择器注入让位样式（不受上游类名变化影响）

### 更新

- **应用图标**：全新 DeepSeek 拟人化形象「蓝色小肥鱼」圆形徽章图标——Q版蓝色大肥鱼少女
  （渐变蓝长发、鲸鳍呆毛、女仆装、鲸尾），小尺寸档使用脸部特写保证任务栏/托盘可读

## v1.0.0（2026-09-17）— 首个公开版本

### 桌面壳

- 🖥️ **真桌面窗口**：Electron 原生窗口 + 自有图标/任务栏标识，一体化自绘标题栏
  （深/浅主题自动切换配色），窗口控制（最小化/最大化/关闭/拖动）齐备
- ⚡ **服务自管理**：自动定位本机 dsh CLI（应用内运行时 → npx 缓存 → 全局 npm →
  `~/.dsh/profiles` → npx 兜底）并启动 `dsh web`，退出时整棵进程树回收；
  端口被残留服务占用时自动探测回收
- 🚀 **启动页**：深色入场动画 + 随机动图 + 实时耗时，服务就绪后淡出进入主界面
- 🔢 **版本徽标 + 版本说明中心**：拉全渠道 packument 检测更新（`latest` / `next` /
  `alpha` 标签都覆盖），点徽标查看当前版本官方说明与历史版本（GitHub Releases，
  中文优先），断网走本地缓存兜底
- ⏳ **应用内更新 + 预热**：更新断点续传（关窗转后台）；装完后备用端口预启新版服务，
  重启免等新文件首过杀软扫描；坏更新自动回退，不会变砖
- 📌 **托盘常驻**：关闭行为（托盘/退出）可记住可改，下载完成气泡提示
- 🛡️ **导航与下载管制**：只放行本机服务与本地页面，外链交系统浏览器；
  下载静默存入系统下载目录

### 平台支持

- **Windows**（x64）：NSIS 安装包（可选目录、卸载向导保留/删除数据可选）、
  单文件便携版、便携 ZIP
- **macOS**（x64 / arm64）：dmg 安装包、便携 ZIP
  - 未做开发者签名：首次打开请用访达右键 →「打开」，或
    `xattr -cr "/Applications/DeepSeek Harness.app"` 清除隔离属性
  - 登录预热（开机预启服务）为 Windows 专属，mac 首次打开需等服务冷启动
- 两平台均需本机已安装 Node.js（≥18）

### 二次元主题插件（dsh-anime-theme）

- 标准 dsh 插件（`dsh.client` + `dsh.bundle`），与桌面壳解耦
- 壁纸 12 款 + 自定义上传、挂件 8 套动图 + 自定义 GIF、浓度/粒子动效可调，
  面板配色跟随深浅主题

### 发布流程

- GitHub Actions：推送 `v*` 标签自动在 Windows + macOS 双平台构建，
  全量产物发布到 GitHub Releases（含本说明）
