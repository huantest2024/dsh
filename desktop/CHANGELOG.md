## v1.0.0（2026-09-17）— 首个公开版本

### 桌面壳

- 🖥️ **真桌面窗口**：Electron 原生窗口 + 自有图标/任务栏标识，一体化自绘标题栏
  （深/浅主题自动切换配色），窗口控制（最小化/最大化/关闭/拖动）齐备
- ⚡ **服务自管理**：自动定位本机 dsh CLI（应用内运行时 → npx 缓存 → 全局 npm →
  `~/.dsh/profiles` → npx 兜底）并启动 `dsh web`，退出时整棵进程树回收；
  端口被残留服务占用时自动探测回收
- 🚀 **启动页**：深色入场动画 + 随机动图 + 实时耗时，服务就绪后淡出进入主界面
- 🔢 **版本徽标 + 版本说明中心**：拉全渠道 packument 检测更新（`latest` / `next` /
  `alpha` 标签都覆盖），点徽标查看当前版本官方说明与历史版本（GitHub Releases，
  中文优先），断网走本地缓存兜底
- ⏳ **应用内更新 + 预热**：更新断点续传（关窗转后台）；装完后备用端口预启新版服务，
  重启免等新文件首过杀软扫描；坏更新自动回退，不会变砖
- 📌 **托盘常驻**：关闭行为（托盘/退出）可记住可改，下载完成气泡提示
- 🛡️ **导航与下载管制**：只放行本机服务与本地页面，外链交系统浏览器；
  下载静默存入系统下载目录

### 平台支持

- **Windows**（x64）：NSIS 安装包（可选目录、卸载向导保留/删除数据可选）、
  单文件便携版、便携 ZIP
- **macOS**（x64 / arm64）：dmg 安装包、便携 ZIP
  - 未做开发者签名：首次打开请用访达右键 →「打开」，或
    `xattr -cr "/Applications/DeepSeek Harness.app"` 清除隔离属性
  - 登录预热（开机预启服务）为 Windows 专属，mac 首次打开需等服务冷启动
- 两平台均需本机已安装 Node.js（≥18）

### 二次元主题插件（dsh-anime-theme）

- 标准 dsh 插件（`dsh.client` + `dsh.bundle`），与桌面壳解耦
- 壁纸 12 款 + 自定义上传、挂件 8 套动图 + 自定义 GIF、浓度/粒子动效可调，
  面板配色跟随深浅主题

### 发布流程

- GitHub Actions：推送 `v*` 标签自动在 Windows + macOS 双平台构建，
  全量产物发布到 GitHub Releases（含本说明）
